/ get up and running

your machine.
your models.

you'll need node.js 20+, npm, and ollama installed. once a model is available locally, omnidev can talk to it without sending prompts to a hosted model provider by default.

get ollama ↗
terminal · quick start
git clone https://github.com/Chayce22315/OmniDev.git
cd OmniDev
npm install
ollama pull qwen2.5-coder:7b
npm run dev -- model status
npm run dev -- ask "explain this project"
